# 환영합니다

이 블로그는 **마크다운 파일**을 읽어 *바로* 웹페이지로 보여줍니다. ~~빌드 단계~~는 필요 없어요.

## 지원하는 문법

- 제목, 문단, 굵게/기울임/취소선
- `인라인 코드`와 코드 블록
- [링크](https://developer.mozilla.org)와 이미지
- 목록, 인용문, 표, 수평선

### 순서 목록

1. `posts/` 폴더에 `.md` 파일을 만든다
2. 상단에 front matter를 적는다
3. `posts/index.json`에 항목을 추가한다

> 글은 짧아도 괜찮습니다. 꾸준히 쓰는 것이 더 중요해요.

## 코드 블록

```js
const greet = (name) => `안녕하세요, ${name}!`;
console.log(greet('블로그'));
```

## 표

| 문법 | 결과 | 비고 |
| --- | :---: | ---: |
| `**굵게**` | **굵게** | 강조 |
| `*기울임*` | *기울임* | 뉘앙스 |
