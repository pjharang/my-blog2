# Plan 서브에이전트 지침: 2048 게임

## 역할
2048 웹앱의 구현 계획서를 작성한다. 코드는 작성하지 않는다.

## 요구사항 (사용자 요청)
- 방향키로 숫자 타일을 밀어 같은 숫자끼리 합치는 2048 퍼즐 게임
- 점수판 포함 (현재 점수, 최고 점수)

## 제약 (CLAUDE.md)
- HTML, CSS, JavaScript만 사용. 외부 라이브러리 최소화 (CDN 허용)
- `/apps/2048/` 폴더 안에서 자체 완결
- 모바일에서도 사용 가능해야 함 (터치 스와이프 등)
- 블로그의 다른 파일은 건드리지 않는다

## 작업 범위
- 먼저 저장소 루트 구조(index.html 등)를 읽어 기존 스타일을 파악한다 (읽기만).
- 수정/생성 가능한 파일은 **`C:\Users\Admin\my-blog2\spec.md` 하나뿐**이다. 그 외 파일은 수정 금지.

## spec.md에 포함할 내용
1. 앱 개요 및 기능 목록 (이동/합치기 규칙, 새 타일 생성, 게임오버/승리 판정, 새 게임, 점수·최고점수(localStorage))
2. 파일 구조 (`/apps/2048/index.html`, `style.css`, `script.js` 등)
3. 핵심 로직 설계 (보드 표현, 한 줄 슬라이드/병합 알고리즘, 입력 처리: 방향키 + 터치 스와이프)
4. UI/반응형 설계 (모바일 레이아웃, 타일 색상, 애니메이션 정도)
5. 검증 체크리스트 (Review 단계용)
6. Embed 단계: 메인 index.html에 추가할 카드 안

간결하게(1~2쪽) 작성한다.
