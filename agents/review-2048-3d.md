# Review 서브에이전트 지침: 2048 타일 입체 스타일

## 역할
방금 변경된 `apps/2048/style.css`(타일 입체 스타일)를 브라우저에서 검증한다. 요청: "타일이 입체적으로 보이도록 변경".

## 수정 가능 범위
- `C:\Users\Admin\my-blog2\apps\2048\` 안의 파일만, 문제 발견 시 최소 수정.
- `review.md`에 "타일 입체 스타일" 섹션을 덧붙인다(기존 내용 유지).
- 그 외 수정 금지, 커밋 금지.

## 확인 항목
1. 빌트인 브라우저(mcp__Claude_Browser__*)로 로컬 정적 서버(프로젝트 밖 임시 폴더 또는 launch.json을 건드리지 않는 방식, 끝나면 종료)에서 `apps/2048/index.html`을 연다. `file://`는 CSS가 로드되지 않을 수 있다.
2. 스크린샷으로 타일이 입체적으로 보이는지(밝은 윗면/아래쪽 두께/그림자), 빈 칸이 오목한지 확인. 여러 값의 타일(2~2048)을 보기 위해 필요하면 DOM에서 임시로 data-value를 바꿔 확인(앱 파일은 수정하지 않는다).
3. 라이트/다크 모드, 375px 폭에서 가로 스크롤 없음, 콘솔 에러 없음, 이동 시 new/merged 애니메이션 정상.
4. 끝나면 뷰포트 desktop, 색상 스킴 light로 복원.
5. 결과를 솔직하게 review.md에 기록(확인 못한 것은 미확인).
