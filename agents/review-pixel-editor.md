# Review 서브에이전트 지침: 도트 아트 에디터

## 역할
`apps/pixel-editor/`의 구현을 검증하고 `review.md`를 작성한다. 기준은 `spec.md` 5절 체크리스트(9항목). 구현을 만든 Build 에이전트와는 별개로, 코드를 처음 보는 입장에서 검증한다.

## 수정 가능 범위
- 생성/덮어쓰기: `C:\Users\Admin\my-blog2\review.md` (기존 내용은 이전 앱의 리뷰이므로 덮어써도 된다. 깃 기록에 남아 있다)
- 수정: `C:\Users\Admin\my-blog2\apps\pixel-editor\` 안의 파일 (문제 발견 시에만, 최소 수정)
- 그 외 파일 수정 금지. 커밋 금지.

## 절차
1. 코드 리뷰: script.js 로직(Pointer Events 처리, Bresenham 보간, flood fill, 되돌리기 스택, PNG 변환, localStorage 예외 처리), HTML/CSS 문제, 접근성 속성.
2. 브라우저 검증: 빌트인 브라우저 도구(mcp__Claude_Browser__*)로 `http://localhost:8000/apps/pixel-editor/index.html`을 연다. 서버가 안 떠 있으면 `.claude/launch.json`의 `blog` 설정으로 시작한다(`preview_start`). 다음을 확인한다.
   - 콘솔 에러 없음
   - 마우스 클릭·드래그로 점이 찍히고 빠른 드래그에도 선이 끊기지 않음 (좌표를 직접 지정한 드래그로 확인)
   - 팔레트 16색 선택과 직접 색 고르기가 현재 색 견본에 반영됨
   - 지우개(투명), 채우기(인접 영역만), 전체 지우기, 되돌리기(스트로크 단위, 전체 지우기 후에도 가능), 격자 토글
   - PNG 저장: 실제 다운로드 대신 `javascript_tool`로 같은 변환 경로를 실행하거나 앱의 저장 함수를 호출해 x1=16x16, x10=160x160, x20=320x320, 투명 배경, 격자선 없음을 확인한다. 다운로드 파일을 저장소에 만들지 않는다.
   - 새로고침 후 그림·색·토글 복원
   - 375px 모바일 폭(`resize_window` mobile): 가로 스크롤 없음, 터치 대상 44px 이상, 캔버스에서 스크롤이 막힘(`touch-action: none` 확인)
   - 다크 모드(`colorScheme: dark`)와 키보드 포커스 표시
   확인 후 뷰포트와 색상 스킴은 원래대로(desktop) 복원한다.
3. 문제가 있으면 수정하고 재검증한다.
4. `review.md`에 체크리스트 항목별 결과(통과/수정/미확인), 발견한 문제와 수정 내용을 기록한다. 확인하지 못한 항목은 솔직히 미확인으로 적는다.

## 완료 보고
항목별 결과 요약(통과·수정·미확인 개수), 수정한 내용, 남은 문제를 5줄 이내로 보고한다.
