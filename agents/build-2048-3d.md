# Build 서브에이전트 지침: 2048 타일 입체 스타일

## 요청
사용자 요청: "타일이 입체적으로 보이도록 변경해 줘."

## 수정 가능 범위
- `C:\Users\Admin\my-blog2\apps\2048\style.css` (주로 이 파일만)
- 꼭 필요하면 `apps/2048/script.js`/`index.html`의 클래스명 관련 최소 수정만 허용. 게임 로직은 건드리지 않는다.
- 그 외 파일 수정 금지, 커밋 금지.

## 요구사항
- 타일에 입체감: 상단 하이라이트(inset 밝은 선), 하단 그림자/두께감(예: `box-shadow`로 아래쪽 어두운 가장자리 + 드롭 섀도), 살짝의 그라디언트. 값별 색상(`data-value`)은 유지하되 그라디언트/그림자가 각 색에 어울리게 한다.
- 보드 칸(빈 셀)은 오목하게 보이도록 inset 그림자.
- 라이트/다크 모드 모두 자연스럽게. `prefers-reduced-motion` 규칙 유지.
- 기존 new/merged 애니메이션이 깨지지 않게 한다. 타일 레이아웃/크기/위치는 바꾸지 않는다.
- 375px 폭에서도 그림자가 보드 밖으로 넘쳐 가로 스크롤이 생기지 않게 한다.
