# Review 서브에이전트 지침: 2048 게임

## 역할
`apps/2048/`의 구현을 검증하고 `review.md`를 작성한다. 기준은 `spec.md` 5절 체크리스트.

## 수정 가능 범위
- 생성: `C:\Users\Admin\my-blog2\review.md`
- 수정: `C:\Users\Admin\my-blog2\apps\2048\` 안의 파일 (문제 발견 시에만, 최소 수정)
- 그 외 파일 수정 금지. 커밋 금지.

## 절차
1. 코드 리뷰: script.js 로직(병합, 새 타일 조건, 승리/게임오버, 입력 처리), HTML/CSS 문제.
2. 브라우저 검증: 빌트인 브라우저 도구(mcp__Claude_Browser__*)로 `file:///C:/Users/Admin/my-blog2/apps/2048/index.html`을 열어(안 되면 로컬 정적 서버 사용 후 종료) 콘솔 에러, 방향키 동작, 점수/최고점수, 새 게임, 375px 모바일 폭 레이아웃(가로 스크롤 없음)을 확인. 확인 후 뷰포트는 desktop으로 복원.
3. 문제가 있으면 수정하고 재검증.
4. review.md에 체크리스트 항목별 결과(통과/수정/미확인), 발견한 문제와 수정 내용을 기록. 확인하지 못한 항목은 솔직히 미확인으로 적는다.
